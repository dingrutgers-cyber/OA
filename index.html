How to read forecast-error measures

Move the pointer over the column headings in the comparison table for a quick definition. In this course, MAD is the primary absolute-error measure and MSE is the primary squared-error measure.

  • Bias (ME): average of Actual − Forecast. Positive bias means the method tends to forecast too low; negative bias means it tends to forecast too high. Bias near zero is good, but can hide large errors that cancel.
  • MAD: mean absolute deviation of forecast errors, equivalent here to MAE. It answers, “How many admissions off are we, on average?”
  • MSE: mean squared error. Large misses receive disproportionately more penalty.
  • RMSE: square root of MSE. Similar emphasis on large misses, expressed again in admissions.
  • MAPE: mean absolute percentage error. Useful for percentage communication but problematic if actual demand is zero or close to zero.

General guideline: do not choose a model from one statistic alone. Check bias, magnitude of error, visual pattern in residuals, model simplicity, forecast horizon, and operational cost of underforecasting versus overforecasting.

Simple regression vs. multiple regression

Simple regression

Admissions = β₀ + β₁Day + ε

This model uses one predictor: Day. It asks whether ICU demand has a systematic linear time trend. It produces one straight fitted line, so every day at the same point in time is treated as if weekday does not matter.

Strength: simple, easy to interpret, and relatively parsimonious for a small dataset.

Limitation: if Saturdays, Fridays, Thursdays, or other weekdays systematically differ, those recurring effects are left in the residuals.

Multiple regression

Admissions = β₀ + β₁Day + weekday effects + ε

This model uses multiple predictors: Day plus weekday indicator variables. Day represents the underlying time trend while the dummy variables allow the expected level to shift according to weekday.

Strength: separates a time trend from a recurring weekly pattern.

Tradeoff: more predictors require more data and create more estimation uncertainty, so improved in-sample fit does not automatically imply better forecasts.

How weekday information is leveraged

Weekday is categorical rather than numerical. Do not code Saturday=1, Sunday=2, Monday=3, and treat that code as a continuous predictor, because that would incorrectly impose equal numerical spacing and a linear weekday ordering. Instead, use 0/1 indicator variables.

With Friday as the reference category, a Saturday observation has Sat=1 and all other weekday indicators=0. A Friday observation has all six weekday indicators=0. Thus the Saturday coefficient estimates the Saturday-versus-Friday difference after controlling for Day.

Justification: the raw data repeat the same seven weekdays for four weeks, so weekday is a plausible source of recurring seasonality. Adding weekday indicators tests whether systematic calendar effects help explain variation beyond the overall time trend. This is especially relevant operationally because Day 29 is known to be Saturday. However, only four observations are available for each weekday, so weekday effects should be treated as suggestive rather than definitive and should be validated with more weeks of data.

Model-building logic for students

  1. Plot the series first and look for trend and repeating weekly behavior.
  2. Fit the simple Day-only regression as a baseline.
  3. Inspect residuals and ask whether weekday information could explain remaining structure.
  4. Add six weekday indicators while omitting one reference weekday.
  5. Compare R² and adjusted R², coefficient estimates, p-values, residual patterns, and importantly forecast performance.
  6. Prefer the more complex model only when the extra structure is interpretable and improves useful predictive performance enough to justify added complexity.

Excel guide: build and interpret the regression

  1. Set up columns: Admissions (Y), Day, and weekday dummy variables. Code a weekday dummy 1 when the observation belongs to that weekday and 0 otherwise.
  2. Omit one weekday: with an intercept, leave one dummy out. In this lab Friday is the reference group. Do not include Friday together with all six other weekday dummies.
  3. Run Excel regression: Data → Data Analysis → Regression. Set Input Y Range to Admissions and Input X Range to Day plus the six included weekday dummy columns. Check Labels when headers are included. Request residuals and a line-fit plot when useful.
  4. Read R Square: proportion of variation in Y explained by the predictors in-sample. Do not treat a higher R² alone as proof that a forecasting model is better.
  5. Read Adjusted R Square: adjusts for the number of predictors and is useful when comparing nested models with different numbers of variables.
  6. Read Significance F: tests whether the regression, collectively, provides evidence that at least one slope coefficient is nonzero.
  7. Read each coefficient: interpret the expected change in Admissions for a one-unit change in that X, holding the other X variables constant. A weekday dummy is interpreted relative to the omitted reference weekday.
  8. Read p-values and confidence intervals: use these to assess statistical evidence for each coefficient. Statistical significance does not automatically imply operational importance.
  9. Inspect residuals: look for systematic time patterns, unequal spread, unusual observations, and omitted seasonality. Forecast errors should not show an obvious pattern the model failed to capture.
  10. Create forecasts: enter future Day values and the correct 0/1 weekday indicators, then calculate Forecast = intercept + sum(coefficient × X). For Days 29–38, continue the weekday cycle.
Excel forecast structure: ŷ = Intercept + bDay(Day) + bMon(Mon) + bSat(Sat) + … + bWed(Wed)

Interpretation habit: always say “holding the other predictors constant.” For example, Saturday = −3.904 means expected Saturday admissions are about 3.9 lower than Friday admissions at the same Day value, according to this fitted model.
